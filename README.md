# 法益共筑 · V0.5

生活情境互动学习网站。400个不同虚构故事、1200个学习环节（每个故事3个环节）；不是1200个独立课程或真实案例。

## 本版行为

- 情境库按400个故事展示；“领鸡蛋”故事只出现一次。
- 四种互动形式：翻开线索、拖动/按钮调整行动顺序、拖动/点击收集相关材料、自己写一段话并对照清单表达。没有把这些练习包装成专业审核结果。
- 情境表达原文不写入本地记录、不提交服务器；只记录完成时间和活动形式。
- 保留12堂中英引导课程。扩展库当前为中文教学草稿，尚未逐条法律复核。
- 豆包Vivi 2.0真实试听（普通话、英语、四川话）随站点提供；完整课堂在线语音按已配置服务调用，标注实际服务商，不静默换成本机音色。
- 特定鸡蛋场景、社区课堂、学生课堂使用新生成配图；其他通用主题保留代码原生SVG，均为示意内容。
- Logo采用透明PNG；新增配图有轻微缩放和悬停效果，互动线索/拖动/收纳有可见反馈。配图并非逐帧人物视频。减少动态偏好会关闭装饰动画。

## 独立运行

Node.js >=22，无第三方运行依赖：

```sh
npm run build:node
npm start
```

默认监听0.0.0.0:8080，使用PORT可变更。Render通过TRUST_PROXY=true支持HTTPS代理；请只在可信代理后开启。

完整课堂语音/问答可直接配置服务密钥，也可暂用同一所有者的原站作为后端：API_RELAY_ORIGIN。该桥只代理/api/tts和/api/chat，保留本地来源校验、签名会话、输入大小与频次限制，不导出原站密钥。后端仍依赖原站及其网络可用性；新域名不保证每种网络都能访问。

秘密值仅在托管平台配置，参见.env.example，禁止提交真实.env。

## 验证

```sh
node scripts/build.cjs
node verify.cjs
node verify-experience.cjs
node verify-doubao.cjs
node verify-relay.cjs
```

前三组覆盖旧324条练习路径、新400个故事的1200个环节、排序/收纳失败恢复、对话隐私、音频解析和服务商边界。接口音频实测与代码测试分别记录；没有把HTTP成功当成真人听感或手机验收。

图片来源与生成提示见content/asset-provenance.md。


## 0.6 更新

中老年200个故事改为600个大字阅读步骤，每页一个继续按钮，无拖动、打字或自查勾选；学生保留四种活动。新增`public/case-illustrations.js`为全部400案例配置场景、人物和主物件，原有36个引导故事也加入情境插图。插图复用同一矢量角色和物件体系，并非400张独立生成的位图。t01-01保留鸡蛋场景，t01-03改为独立生成的礼品推销场景。

微信等嵌入浏览器的失败日志为`POST /api/tts 401`；状态接口现返回20分钟有效的签名会话，前端仅存内存，并通过`X-Fayi-Session`传回，Cookie仍兼容。来源检查和限流保留；没有关闭验证或把服务密钥传到前端。`node verify-session.cjs`覆盖完全无Cookie、过期重试、音频播放调用、伪造令牌与跨源拒绝。浏览器真实听感仍需设备试听。

分享栏统一复制Render网址。旧chatgpt.site地址可能在内容加载前被Cloudflare阻止，应用无法解除该平台拦截。新页面已独立部署，在线语音仍经原服务器转接。
