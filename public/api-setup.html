开发与部署说明 / Setup guide

把自由对话和自然语音接进来

阿里云语音已配置；豆包语音适配已准备，尚未配置火山引擎密钥。DeepSeek自由问答需要API账户有可用余额。不要把 API Key 写在公开网页、代码仓库或聊天消息里。

优先使用豆包声音

豆包App与火山引擎的豆包语音API是不同入口。网站需要有语音合成权限的火山引擎密钥；不能使用DeepSeek或阿里云密钥代替，也不能保证与豆包App中某个音色完全相同。

  1. 打开火山引擎语音API Key设置，登录并按控制台要求开通相应语音资源。无需将密钥发到聊天。
  2. 新版控制台生成的密钥，在本站托管设置添加机密 DOUBAO_API_KEY。旧版控制台使用 DOUBAO_APP_ID 和 DOUBAO_ACCESS_KEY 两个机密。
  3. 默认资源 seed-tts-2.0、默认音色 zh_female_vv_uranus_bigtts。需要账号具备匹配资源权限。可在服务端设置 DOUBAO_RESOURCE_ID、DOUBAO_SPEAKER、DOUBAO_SPEAKER_EN。
  4. 保存后重新部署，再在语音设置中选择“豆包自然语音”，实际试听普通话、英文和四川话。

当前豆包声音尚未接通；代码只完成模拟请求检查。API按供应商规则使用额度或计费，不要求每位访客自己开通账号。网页上的固定教学内容可独立使用。

1. 大模型负责什么

让用户在当前教学情境里用自己的话提问，生成更通俗的解释，并围绕一个误区追问。模型不替代专业人员，不判断真实案件责任、赔偿或诉讼结果。语音自然度主要由语音合成服务决定，换文本大模型不会自动让声音变好听。

开通与配置

  1. 在 DeepSeek 开放平台注册账号，按平台要求开通 API 和计费，创建 API Key。聊天产品账号或会员不等于本站已获得 API 权限。
  2. 在部署环境的服务端机密变量中配置 DEEPSEEK_API_KEY；模型名使用 DEEPSEEK_MODEL=deepseek-flash。若更换模型，需按官方文档验证当前可用名称。
  3. 配置一个至少32字节的随机服务端机密 API_SESSION_SECRET，再设置 ENABLE_PUBLIC_AI=true。这一步会允许公开访客产生模型/语音调用，先确认账号预算与用量限制。
  4. 重新部署。同源 /api/status 中的 chatReady 会变成 true；情境页将出现提问输入框。
  5. 用真实请求检查响应、超时、错误回退和教学边界，保留检查记录。没有真实调用前，不称为“已接入”。

2. 好声音与方言，接专门的语音服务

当前页面提供本机音色、语速设置与试听。浏览器不一定提供四川话等音色，也不能保证情绪表现。真正自然的声音需要合适的模型、音色和实听调校。

  1. 在阿里云百炼按要求开通 API 服务，创建与北京地域匹配的 API Key，保存在服务端机密 DASHSCOPE_API_KEY。
  2. 本原型适配 Qwen-TTS HTTP 接口，默认 TTS_MODEL=qwen3-tts-flash，普通话/英语音色 Serena，四川音色 Sunny。均需按当前账号与官方音色表实际验证。
  3. 可以分别设置 TTS_VOICE_ZH、TTS_VOICE_EN、TTS_VOICE_SC、TTS_VOICE_YUE（粤语默认Kiki）。不能把不支持相应模型或方言的音色随意混用。
  4. 若要情绪指令，可选择官方支持指令控制的模型。本适配器对名称包含 instruct 的Qwen-TTS模型发送温和、耐心、自然的说明；必须用该模型支持的音色实测。默认 Flash 模型不承诺情绪控制。
  5. 重新部署后，/api/status 的 ttsReady 为 true，可在“语音与语言”里选择自然语音服务。没有密钥、地区不匹配或接口失败时回退本机音色。

已准备普通话、四川话、粤语和英语音色路由，仍需开通后逐项实听；闽南语、上海话等还需要按模型与音色适配和检验；本次并未实现中国所有方言。四川口语字幕也是示范稿，需要本地使用者复核。

3. 已准备的保护与验证范围

密钥仅放在服务端；接口使用同源检查、短期签名会话、输入长度限制、超时、来源范围与原型级限流。不保存提问、音频或语音转写原文。内存限流不是全局持久配额；公开大规模使用前，应补充持久限流、预算控制和专业内容检查。

当前已检查本地接口逻辑和网页流程，不代表已经对商业模型、真实方言声音或所有设备完成测试。当前内容、英文教学译文和四川口语都未取得专业审核。
